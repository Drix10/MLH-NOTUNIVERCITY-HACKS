# SaveWater: MLH NotUniversity Hacks Project

**SaveWater** is my project for the **MLH NotUniversity Hacks** hackathon: a website about preventing water wastage, with tools that make the information easier to share and access. Live at **[savewater.online](https://www.savewater.online)**.

## Features

- **Water-saving idea and algorithm** on the main page for reducing wastage
- **Problems and solutions**: a page on water issues across North America
- **QR code generator** to share pages and notes
- **Image recognition** for everyday objects
- **Text-to-speech** and **speech-to-text** converters

## Tech

HTML, CSS (Bootstrap, AOS animations) and JavaScript. No build step.

```bash
git clone https://github.com/Drix10/MLH-NOTUNIVERCITY-HACKS.git
cd MLH-NOTUNIVERCITY-HACKS
npx serve .
```
